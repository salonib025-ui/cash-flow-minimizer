💸 Cash Flow Minimizer

A C++ and Web-based application designed to minimize the total number of monetary transactions required to settle group debts using Graph Algorithms (Greedy Approach).

 📌 Features
1. Greedy Settlement Algorithm: Calculates net balances and optimizes settlements to minimize total transaction count.
2. C++ Console Application:Full interactive CLI menu for inputting dynamic group sizes, participant names, and debt matrices
3. Web Interface: Interactive HTML/JS dashboard allowing visual matrix inputs, automated calculations, and smooth UI flow
4. Input Validation:Prevents negative debt entries and enforces valid participant inputs.
